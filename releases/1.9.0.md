## What changed

- Client tokens: an authorised device proves itself with a server-issued token
  rather than by its IP address.
- Flat photo storage under `<photos root>/<YYYY-MM>/`, with the library scanner
  walking recursively so older per-user directories still resolve.
- A configurable photos root (Settings → Storage) that takes effect without a
  restart.

## What this means for your install

No action beyond upgrading normally: the schema gained the client-token columns
through a migration that had already been applied before this release was
tagged.

## Action required

None.
