Server setup

Enter the address of the Spore-Photos server you want to use.

For a local server over Tailscale, use its reachable IP and port. The address must serve the full Spore-Photos app, not just /api.
Still stuck?

If the buttons above do nothing, reset the app manually: Android Settings → Apps → Spore-Photos → Storage → Clear data. Clearing cache is not enough — the saved address lives in app data. The app then returns to this setup screen.
